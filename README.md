An intelligent ticket booking platform designed to provide secure booking, real-time seat availability and smart crowd management.

**✨ Key Features**

- ⚡ Apache Kafka for event-driven communication.
- 🤖 Python-based AI services for recommendations and demand prediction.
- 🔐 JWT-based authentication.
- 🎫 QR-code-based electronic tickets.
